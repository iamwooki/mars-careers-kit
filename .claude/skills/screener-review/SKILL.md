# 심사관·면접관 검수 (screener-review)

사실 검수를 통과한 자소서도 떨어진다. 이 스킬은 **진실이지만 떨어지는 이유**를 찾는다.
수천 장을 거르는 심사관은 읽지 않고 훑는다. 훑는 5초 안에 세 가지를 판단한다 — 자격이 되는가,
우리 직무 사람인가, 왜 옮기는가. 그 다음에야 문장을 읽는다. 검수도 같은 순서로 한다.

## 입력
- 자소서 md (`01_resume_draft*.md` 또는 `02_resume_final.md`)
- `00_input.md`(공고 수행직무·지원자격·채용인원) — 없으면 `00_target.md` 2장·4장
- 선행 사실 검수 리포트 (있으면 — 사실 지적은 반복하지 않는다)

## 절차

### 1. 5초 스캔 (S1~S3)
`references/screener-checklist.md`의 S 항목. 자소서가 심사관에게 **스스로를 어떻게 소개하는지**를 본다.
- S1 자격요건 산수: 자소서 문장만으로 심사관이 계산하는 관련 경력 연수 vs 공고 요건. 지원자가 실제로
  충족해도 자소서가 "3년 + 딴 일 3년"으로 읽히면 미달로 분류된다.
- S2 키워드 밀도: `scripts/keyword_scan.py`로 직무 어휘 vs 전 직장 내부 어휘를 센다. 직무 어휘가 0에
  가까우면 "다른 직군 사람"으로 분류된다.
- S3 이직 사유: 경력직이면 반드시 본다. 없으면 이탈 리스크로 메모된다.

### 2. 수행직무 커버리지 매트릭스
공고 수행직무 항목마다 [직접 사례 있음 / 주장만 있음 / 없음]을 판정한다. "주장만 있음"(예: "낯설지 않습니다",
"늘 해온 일입니다")은 없음과 같다 — 사례 없는 주장은 면접에서 무너지고, 심사관은 그것을 안다.

### 3. 문항별 탈락 사유 (Q 항목)
문항 취지 일치, 첫 문장의 자백 효과, 대표 성과의 격(格), 수치 귀속, 해독 3초 초과 문장, 자해 문장,
경쟁사 실명, 5년차가 쓸 문장이 아닌 것(자격 취득 약속·학부 과제 분량).

### 4. 구조 (X 항목)
배치 역전(최강 카드가 채점 문항 밖에 있음), 소재 반복(같은 이야기 3회), 재료 흩뿌리기(포부 문항에 새 경력).

### 5. 경쟁자 대비
채용인원과 직무로 경쟁 풀을 추정하고(예: SI PMO·컨설팅펌·감리법인 출신), 그들이 쓰지 않을 문장을 짚는다.

### 6. 판정을 뒤집을 조건
탈락 사유를 고치는 순서를 3개 이내로 쓴다. 1번은 사용자 입력이 필요한 경우가 많다 — 그것을 숨기지 않는다.

### 7. 면접관 모드 (요청 시 또는 최종본 단계)
`references/screener-checklist.md`의 I 항목. 자소서의 모든 수치·주장·갭에서 질문을 만들고,
"무너지는 문장" 목록과 30초 답변 골격(인정 → 학습·대체 근거 → 직무 연결)을 만든다.

## 작성 원칙
- **역할을 유지한다.** 격려·칭찬 없음. 통과 항목은 쓰지 않는다. 심사관은 잘한 점을 메모하지 않는다.
- **근거를 자소서 문장에서 인용한다.** "약해 보인다"가 아니라 "○○ 문장이 △△로 읽힌다".
- **고치지 않는다.** 수정은 resume-writer의 몫. 단 "뒤집을 조건"은 구체적으로.
- 사실 검수와 겹치는 지적(수치 오류·글자수)은 반복하지 않고 해당 리포트를 가리킨다.

## 출력
`_workspace/review_{지원처}_심사관.md` — 구조: 0 판정 / 1 5초 스캔 표 / 2 수행직무 커버리지 / 3 문항별 /
4 구조 / 5 경쟁자 대비 / 6 뒤집을 조건 / (7 면접 예상 질문). 반환 메시지: 판정 한 줄 + 뒤집을 조건 3개.
