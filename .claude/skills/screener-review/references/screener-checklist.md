# 심사관·면접관 체크리스트

각 항목은 "무엇을 보는가 / 왜 떨어지는가 / 자소서에서 찾는 신호" 순.

## S. 5초 스캔
| # | 본다 | 왜 떨어지나 | 신호 |
|---|---|---|---|
| S1 | 자격요건 산수 | 심사관 1차 업무는 미달자 제거. 자소서 문장으로 계산한 관련 경력이 요건 미만이면 실제와 무관하게 제거 | "N년째, 그중 M년은 ○○" 뒤에 나머지가 딴 직군으로 서술됨. 파견·TF·연구 기간이 직무 어휘 없이 서술됨 |
| S2 | 직무 키워드 밀도 | 키워드 스캔에서 직군이 다르게 분류됨 | 공고 수행직무 명사(사업비·검수·산출물·일정·수행사 등) 0회, 전 직장 내부어(위원회·TF·안건·보도자료) 다수 |
| S3 | 이직 사유 | 경력직은 "왜 옮기나"가 없으면 이탈 리스크 | 지원동기가 "제가 해 온 일을 여기서 하는 자리" 식 동어반복, 현 직장을 떠나는 이유 없음 |

## C. 수행직무 커버리지
수행직무 항목별로: 직접 사례(사업명·규모·본인 행동·결과) / 주장만("낯설지 않다", "늘 해온 일") / 없음.
가장 정량적·전문적인 항목(원가·산정·검수 등)이 비면 치명적 — 그 항목이 경쟁자와 갈리는 지점이다.

## Q. 문항별
| # | 본다 | 신호 |
|---|---|---|
| Q1 | 문항 취지 일치 | 지원동기 문항의 80%가 경력 요약, 포부 문항에 새 경력 등장 |
| Q2 | 첫 문장의 자백 효과 | "○○ 중 하나였습니다", "직접은 아니지만" — 관계의 약함을 첫 줄에서 고백 |
| Q3 | 대표 성과의 격 | 직무 수준 대비 낮은 일(서식 정리·문서 취합·일정 스크랩)이 대표 성과로 놓임 |
| Q4 | 수치 귀속 | 조직 예산·문서 페이지 수·타인 성과를 본인 수치처럼 배치. 심사관 질문: "그 숫자에서 당신 몫은?" |
| Q5 | 해독 3초 | 내부 용어·추상 명사·번역투로 3초 안에 뜻이 안 잡히는 문장. 심사관은 해독하지 않고 넘김 |
| Q6 | 자해 문장 | "새로 배워야 합니다", "경험은 없지만", 경쟁사 실명, 취득 못 한 자격 약속 |
| Q7 | 연차 부적합 | 경력직인데 학부 과제·수료 교육이 분량의 15% 이상 → "쓸 경력이 부족하다" 신호 |
| Q8 | 기관 상식 오류 | 해당 기관에 이미 있는 제도·시스템을 없는 것처럼 전제한 제안 → "우리를 모른다" |
| Q9 | 상투 문장 | 설립연도·설립 목적 인용, "최고의 ○○가 되겠습니다" |

## X. 구조
| # | 본다 | 신호 |
|---|---|---|
| X1 | 배치 역전 | 가장 직무다운 카드가 지원동기·포부 문항에 있고, 경력·성과 문항에는 약한 카드 |
| X2 | 소재 반복 | 같은 프로젝트·같은 산출물이 3문항 이상 등장 → "한 가지 일만 한 사람" |
| X3 | 재료 흩뿌리기 | 문항마다 새 경력 한 토막씩 → 깊이 없음 |
| X4 | 어휘 불일치 | 문항 1은 직무 어휘, 문항 2는 정책 어휘 — 같은 사람이 쓴 것 같지 않음 |

## P. 경쟁자 대비
채용인원 ≤ 3이면 경쟁 풀을 구체적으로 상정한다(직무별 전형 경력자). 그들이 절대 쓰지 않을 문장(Q6)과
그들이 반드시 쓸 사례(C에서 비어 있는 항목)를 대조한다.

## I. 면접관 모드
질문 생성 규칙 — 자소서의 다음 요소마다 1개 이상:
1. **수치 검증**: "110억은 어떻게 산출했나, 당신 기여는 몇 %인가"
2. **갭 직격**: 커버리지 '없음' 항목 — "○○ 해본 적 없죠?" (답 골격: 인정 → 학습·대체 근거 → 직무 연결, 30초)
3. **이직 사유·정착**: "왜 지금, 왜 우리, 3년 뒤 또 옮기나"
4. **번역 검증**: 전 직장 경험을 이 직무 언어로 즉석 번역시키기 — "그 일을 우리 직무로 말하면?"
5. **주장 문장 확인**: "낯설지 않다"고 쓴 것 → "그럼 사례 하나만"
6. **기관 이해**: 방향 문항 제안에 대해 "우리는 이미 ○○가 있는데?"
출력: 질문 / 자소서 근거 문장 / 무너질 위험(상·중·하) / 답변 골격 한 줄.
