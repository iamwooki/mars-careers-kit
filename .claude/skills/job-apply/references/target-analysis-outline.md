# 00_target.md 표준 구조

career-analyst가 작성한다. 각 절의 목적을 이해하면 공고 형태가 달라도 같은 구조로 쓸 수 있다.

## 1. 직무 해설 — 이 자리는 무엇을 하는 자리인가
- 1.1 한 문장 비유 (건축·병원 등 일상 비유 + 비유↔현실↔이 직무의 역할 3열 표)
- 1.2 핵심 책무 풀이 — 책무마다 "장면" 하나 (월간 회의에서 무슨 말을 하는 사람인가)
- 1.3 수행직무 항목별 실제 장면 표
- 1.4 필요지식 — 용어 정의 + 왜 필요한가
- 1.5 필요기술 / 1.6 태도(기관 핵심가치와 연결) / 1.7 직업기초능력
- 1.8 전형 절차와 필기·실기 추정 — 추정은 반드시 [추정] 표시, 공고 확인 항목 목록

## 2. 요구 역량 키워드 표
R01, R02… 번호를 붙인다. 열: 공고 문장 / 추출 키워드 / 중요도(상·중). 이후 모든 매칭은 R번호로 참조.

## 3. 경험 매칭
- 3.1 카드별 매칭표: 카드 / 요지 / 대응 R번호 / 유사도(높음·중간·낮음) / **카드 인용문**(근거 없는 유사도 금지)
- 3.2 R번호별 커버리지: 충족 카드 / 수준 / 갭
- 3.3 갭 정리: 항목 / 상태(근거 없음·부분) / 간접 근거 / 보완 제안 / **지식형·경험형 구분**

## 4. 지원 가부
- 4.1 **지원자격 판정 먼저** (학위·경력 연수 합산·필수 자격). 경력은 카드 기간으로 실제 계산.
- 4.2 종합 유사도 — 가중치 표 + "분석자 추정치이며 기관 기준 아님" 명시
- 4.3 강점 3 / 4.4 약점 3 (근거 카드 병기)
- 4.5 채용담당자 관점 — 통과시킬 이유 / 떨어뜨릴 이유
- 4.6 결론: 지원 권장 / 조건부 / 비권장 + 조건 표
- 4.7 필기·실기·면접 대비 포인트

## 5. 문항–카드 매핑
문항마다: 주 카드 / 보조 카드 / 사용 가능 수치(증빙 확인된 것만) / 두괄식 첫 문장 후보 / 구성 / 피할 것.
마지막에 배분 요약표 — 한 카드가 두 문항의 주 카드가 되지 않게.

## 6. 확인 필요
- 6.1 draft 카드 사용 목록(우선순위) / 6.2 수치 출처·공개 여부 대조표 / 6.3 사용자 질문(5개 이내) / 6.4 카드 간 사실 충돌
