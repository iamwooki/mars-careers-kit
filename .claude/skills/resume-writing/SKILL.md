# 자소서 작성

## 원칙

1. **카드에서 출발한다.** 자소서는 창작이 아니라 `inventory/`의 confirmed 카드를
   문항에 맞게 재조합하는 것이다. 카드에 없는 사실을 지어내지 않는다.
   재료가 부족하면 쓰다 마는 게 아니라 career-inventory 인터뷰로 돌아간다.
2. **두괄식.** 각 문항의 첫 문장은 카드의 "한 줄 요약"을 변형한 결론이다.
   "저는 어려서부터…" 식 배경 서사로 시작하지 않는다.
3. **문항이 묻는 것에만 답한다.** 지원동기 문항에 성과 자랑을, 협업 문항에 기술 스택을
   욱여넣지 않는다. 문항 → 카드 매핑을 먼저 하고 쓴다.
4. **숫자는 카드의 I(증빙)가 있는 것만.** 근거 없는 수치는 면접에서 무너진다.
5. **분량 준수.** 문항별 글자수 제한이 있으면 ±5% 이내. 제한이 없으면 문항당 500~700자.

## 본인 문체 기준 (초안 전에 반드시 읽는다)

`applications/_reference/` 폴더에 **본인이 AI 도움 없이 직접 쓴 글**(예전에 합격한 자소서, 직접 쓴 보고서·메일)이 있으면 초안 전에 읽고 그 문체에 맞춘다. 없으면 사용자에게 "직접 쓰신 글이 있으면 한두 편 넣어 주세요"라고 먼저 권한다. 문체만 가져온다 — 거기 적힌 사실을 쓰려면 inventory 카드에 반영된 것만 쓴다.

## 작업 순서

1. **지원처 분석**: 채용공고·기관 정보에서 요구 역량 키워드를 추출한다.
   `applications/{지원처}/00_target.md`에 기록: 기관명, 직무, 문항 목록, 요구 역량, 마감일.
2. **카드 매핑**: 각 문항에 대해 inventory 카드 중 keywords·category가 맞는 것을 1~2장 선정.
   매핑 표를 `00_target.md`에 추가한다. 한 카드를 여러 문항에 중복 사용하지 않는다
   (같은 경험이 반복되면 경험 폭이 좁아 보인다).
   **경험 추천 → 사용자 조합(기본)**: 매핑을 확정하기 전에 문항별 후보 경험 3~5개와 조합안 2개를 사용자에게 먼저 보여 주고
   (양식: `.claude/skills/job-apply/assets/00_materials_template.md` → `00_materials.md`), 사용자가 고른 조합으로 쓴다.
   사용자가 "바로 써줘"라고 했거나 마감이 임박했을 때만 추천안으로 곧바로 진행한다. 사용자가 직접 쓴 문장은 재료로 그대로 쓴다.
   **키워딩 → 본문**: 본문을 쓰기 전에 문항마다 핵심 키워드 2~3개와 소제목을 먼저 정한다(사용자 확인). 본문은 그 키워드를 정의하며 시작하고 같은 키워드로 닫는다.
   **지원동기**는 회사의 실제 서비스·시스템을 먼저 검색해(출처 기록) 내 직무 경험과 맞는 것을 고른 뒤 쓴다.
3. **초안 작성**: 문항별로 [결론 → 상황·과제(간결) → 행동(구체) → 성과(숫자) → 직무 연결] 구조.
   비중은 행동 40% : 성과 30% : 상황 20% : 연결 10%.
4. **자기 검증**: 아래 체크리스트를 통과 못 하면 스스로 고친 후 제출한다.

## 체크리스트

- [ ] 모든 문항이 두괄식으로 시작하는가
- [ ] 모든 숫자에 카드의 증빙(I)이 존재하는가
- [ ] 지원처 요구 역량 키워드가 자연스럽게 포함됐는가 (기계적 나열 금지)
- [ ] 글자수 제한 준수 (공백 포함/제외 기준을 공고에서 확인)
- [ ] 같은 경험이 두 문항에 중복 등장하지 않는가
- [ ] 문장이 짧은가 (한 문장 60자 이내 권장, 번역투·피동형 제거)

## 산출 위치

`applications/{지원처}/01_resume_draft.md` — 문항별 제목 + 글자수 표기.
검수 후 최종본은 `02_resume_final.md`.

## 문체 교정

초안을 위 "본인 문체 기준"(직접 쓴 글)과 대조한 뒤, AI 문체 점검용 스킬을 따로 갖고 있으면 돌린다(없으면 "~를 통해", 대시(—) 남발, 세 개씩 나열하는 버릇을 직접 찾아 고친다).

초안 완성 후 im-ai-copyeditor-grammar 스킬(설치돼 있다면)로 맞춤법·문체를 교정한다.
경험기술서처럼 개조식이 요구되면 문장을 명사형으로 끊고 한 줄에 한 사실만 둔다.
